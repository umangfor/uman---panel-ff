# UMANG FF PANEL

A mobile-friendly, black-and-red browser practice companion with:
- 20-second tap-target aim trainer
- Local practice statistics (sessions, total hits, best hits per round)
- Editable sensitivity notes saved in your browser
- HUD notes planner with device-local saving
- Responsive layout for phones and desktop

## Run locally
Open `index.html` in a modern browser. No build tools or server are required. The Google Fonts import requires an internet connection; the page otherwise works with system font fallbacks.

## Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then save.
4. Wait for GitHub Pages to publish the site. The URL will appear in the Pages section.

## Important
This is an independent fan-made practice companion. It does not connect to, modify, or automate Free Fire. It does not provide auto-aim, auto-headshot, cheats, game-memory editing, or anti-cheat bypasses. It is not affiliated with Garena. Settings, HUD notes, and statistics are stored only in the browser on the device and are not uploaded.
